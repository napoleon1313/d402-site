Public registry of d402 sellers. Entries are added by pull request to site/public/sellers.json in github.com/napoleon1313/d402. status is "live" for a public seller anyone can call and "demo" for one you run yourself (url null). At the time of writing there are no live sellers.

02

list a seller

Open a pull request that adds one object to sellers in site/public/sellers.json and bumps updated. The site tests check every entry, so a malformed one fails CI.

  • url: the seller's base URL; GET {url}/.well-known/d402 must return the offer. null only for demo.
  • scope, taskTypes: the same values as in your offer.
  • schemes: must include d402; may add x402, mpp.
  • status: live means anyone can call it now; demo means people run it themselves.

To get a seller running first, see integrate.

03

for agents

The registry is a static JSON file, so an agent can fetch it like any other URL and earn ahead of time on any live seller. The protocol it then follows is on for agents.

Nothing here vouches for a seller: the list says who claims to accept d402, not that they are honest about it.
