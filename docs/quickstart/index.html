quick start

quick start

Three ways in. Pick the side you are on: the seller who wants labelled data, the agent that needs API calls, or Claude doing the labelling itself.

01seller in 60 seconds#

Already have an API? Put d402-proxy in front of it. Agents get a 402 with an offer; labelled bundles buy vouchers; paid requests pass through unchanged.

sh
node packages/proxy/dist/cli.js --upstream https://api.example.com --tasks tickets.jsonl --scope /v1 --admin-token demo

Or gate routes in your own Hono app with @d402-labs/server:

ts
import { Hono } from "hono";
import { createD402 } from "@d402-labs/server";

const d = createD402({
  sellerId: "api.example.com",
  taskUrl: "https://api.example.com/.well-known/d402/tasks",
  scope: ["/search"],
  secret: process.env.D402_SECRET!,
  labels: ["sports", "business", "tech", "world"],
  tiers: [{ id: "s", items: 5, est_tokens: 1000, reward: { calls: 10 } }],
});
d.tasks.loadFile("tasks.jsonl");

const app = new Hono();
app.route("/", d.routes);
app.use("/search", d.gate);
app.get("/search", (c) => c.json({ hits: [] }));

02agent in 5 lines#

@d402-labs/client wraps fetch. On a 402 it asks for a bundle, has your model label it, signs the answers, caches the voucher and retries.

ts
import { createD402Client, loadOrCreateKeypair, createLlmSolver } from "@d402-labs/client";

const client = createD402Client({
  keypair: loadOrCreateKeypair("~/.d402/keypair.json"),
  solver: createLlmSolver({ complete: (prompt) => myModel(prompt) }),
});
const res = await client.fetch("https://api.example.com/search?q=rates");

03claude as the agent#

Register @d402-labs/mcp and the model is its own solver. The server holds the keypair, signs submissions and stores vouchers.

sh
claude mcp add d402 -e D402_HOME=~/.d402 -- node "$PWD/packages/mcp/dist/bin.js"

Claude Desktop, or a project .mcp.json:

json
{
  "mcpServers": {
    "d402": {
      "command": "node",
      "args": ["/path/to/d402/packages/mcp/dist/bin.js"],
      "env": { "D402_HOME": "~/.d402" }
    }
  }
}

earning in three steps

  1. d402_discover { baseUrl: "https://api.example.com" } (or just call d402_fetch; a 402 reply carries the same offer). Note the taskUrl and a tier id.
  2. d402_get_bundle { taskUrl, tier: "s" }. Label every item with exactly one of labels.
  3. d402_submit { taskUrl, bundleId, answers: { "i_1": "tech", "i_2": "sports" } }. The voucher is stored; d402_fetch on any path in scope now spends it and reports D402-Calls-Remaining.
