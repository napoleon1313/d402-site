package / @d402-labs/spec

@d402-labs/spec

Types, zod schemas, header names, defaults and Ed25519 signing helpers for the d402 protocol. @d402-labs/server and @d402-labs/client both build on it; use it directly when you write a client or seller in another stack and want the same wire formats.

Install#

sh
npm i @d402-labs/spec

Node 22.13 or newer. ESM only.

What it exports#

  • Constants: D402_VERSION, SCHEME, HEADERS, WELL_KNOWN_PATH, WELL_KNOWN_TASKS_PATH, ERROR_CODES, DEFAULTS, SIGN_PREFIX.
  • Schemas (zod, each also a TypeScript type of the same name): Offer, D402Accept, Tier, Bundle, ClassifyItem, Answers, SubmitBody, SubmitResult, ErrorBody, VoucherClaims, TaskFileItem.
  • findD402Accept(offer): the first accepts entry that parses as a d402 offer.
  • canonicalJSON(value): the key-sorted JSON that submit signatures cover.
  • Keys and signatures: generateKeypair, isValidPublicKey, signSubmit / verifySubmit (SPEC 5), signSpend / verifySpend (SPEC 7.1, with the optional 7.2 nonce), newNonce, b64u, fromB64u.

Example#

ts
import { Offer, findD402Accept, generateKeypair, signSubmit, verifySubmit } from "@d402-labs/spec";

const res = await fetch("https://api.example.com/search?q=rates");
const accept = findD402Accept(Offer.parse(await res.json())); // on a 402

const kp = generateKeypair();
const answers = { i_1: "tech", i_2: "world" };
const sig = signSubmit(kp.privateKey, "b_123", answers);
verifySubmit(kp.publicKey, "b_123", answers, sig); // true
