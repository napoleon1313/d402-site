packages

packages

A pnpm monorepo. Each page below is the package README, rendered from the repo at build time. Packages are not on npm yet: pnpm build and run the bins from packages/*/dist.

packages#

  • @d402-labs/spec zod schemas, header names, defaults, ed25519 signing helpers read
  • @d402-labs/server hono middleware for sellers: offer, bundles, grading, trust, vouchers read
  • @d402-labs/client fetch wrapper for agents: earns on 402, caches vouchers, retries read
  • @d402-labs/mcp agent-side mcp server: the llm is its own solver read
  • @d402-labs/mcp-seller the seller as a remote mcp server, tools paid in labelled data read
  • @d402-labs/proxy gate any existing api with one command, no code read
  • @d402-labs/pool the task marketplace: vendors post work, any site gates with it read
  • @d402-labs/x402 x402 usdc as a payment scheme beside d402 in one 402 read
  • @d402-labs/mpp mpp as a payment scheme beside d402 in one 402 read

clients#

  • clients/python same keypair and voucher files as the ts client read
  • clients/curl the whole protocol in a bash script read
